# 3D: hero type and 3D assets

`tools/render3d` path-traces extruded objects to **transparent PNG frames** that Remotion places in
world space beside (or behind) the speaker. One WebGL2 page (`scene3d.html`) driven headless by
`render.mjs`; no Blender, no 3D package, no AI video.

What you get:

- **Hero type:** any words in any font you have the file for, extruded with a rounded bevel, a
  metal body and a coloured face. Words swing in from depth landing ON their word, idle with a slow
  perspective wobble (so they never read as stickers), can "light up" with a nod on a later word,
  and swing away on the exit word.
- **3D assets:** any logo or icon silhouette (SVG or PNG alpha) extruded the same way, or set on a
  disc as a raised relief (a medallion / coin-style badge). Spin, tilt, idle.
- Studio dome lighting (key softbox, fill, two coloured rims, a top strip for the bevels, floor
  bounce), GGX microfacet metal, a dielectric or metallic face, thin-lens depth of field, 180-degree
  shutter motion blur. Up to 4 objects per shot.
- Frames are pure functions of the plan frame: render any frame in any order, resume a killed render.

## Setup

```bash
cd tools/render3d
npm install                                        # puppeteer + its Chrome (~170 MB)
./fetch_font.sh 'ofl/sora/Sora[wght].ttf' Sora.ttf # any OFL font from github.com/google/fonts
```

## Hero type, step by step

1. **Outlines** (HarfBuzz-shaped, so kerning is the font's own):
   ```bash
   cd examples
   uv run --with uharfbuzz --with fonttools ../glyphs.py --font ../fonts/Sora.ttf --weight 800 \
       --out paths.json BUILD FAST
   ```
2. **Shot file** (`examples/hero.json`):
   ```jsonc
   {
     "width": 1080, "height": 420, "fps": 30, "spp": 128,
     "f0": 0, "f1": 90,                         // plan frames to render
     "paths": "paths.json",
     "camera": {"distance": 2600, "aperture": 10},   // aperture 0 = no depth of field
     "light": {"rimA": "#08d1e3", "rimB": "#ffb35c", "key": 3.4},
     "objects": [
       {"text": "BUILD", "x": -250, "y": 0, "width": 420, "depth": 44, "bevel": 4.5,
        "body": "dark-metal", "face": "#f2f4f5", "faceDim": "#0b0d0e",
        "in": 12, "lit": 24, "out": 78},
       {"text": "FAST", "x": 250, "y": 0, "width": 360, "face": "#ffb35c", "faceDim": "#0b0d0e",
        "in": 20, "lit": 34, "out": 78}
     ]
   }
   ```
3. **Stills first**, and look at them over a dark and a light background:
   ```bash
   node ../render.mjs hero.json --stills=8,30,60 --spp=48 --out=check/h
   ```
4. **Frames** (resumable; existing frames are skipped):
   ```bash
   node ../render.mjs hero.json --clip --dir=<project>/remotion/public/hero1
   ```
5. **Plan event** (frames in the shot = frames in the plan):
   ```json
   {"type": "hero3d", "at": 412, "until": 478, "seq": {"dir": "hero1", "f0": 400, "f1": 490},
    "x": 960, "y": 300, "w": 1080, "h": 420, "behind": false,
    "reason": "lands on 'build fast', the claim the video pays off"}
   ```
   With `"behind": true` inside a roto window, it passes behind the speaker.

Set the shot's `f0`/`f1`/`in`/`out`/`lit` to the PLAN frames of the words (from words.json or the
resolved plan), not to local times: then a frame file `f0412.png` is exactly plan frame 412.

## 3D assets

```jsonc
// examples/logo.json: extruded silhouette, spinning
{"width": 640, "height": 640, "f0": 0, "f1": 120,
 "objects": [{"image": "mark.svg", "width": 360, "depth": 60, "bevel": 6,
              "body": "steel", "face": "#e9ecef", "faceMetal": true, "faceRough": 0.1,
              "enter": "none", "idle": 0.3, "spin": {"start": -30, "rate": 40}}]}

// examples/medallion.json: the silhouette as a raised relief on a disc
{"objects": [{"image": "mark.svg", "width": 300, "depth": 26, "relief": 7, "bevel": 3,
              "medallion": {"radius": 230}, "body": "gold", "face": "#ffd27a", "faceMetal": true,
              "enter": "none", "spin": {"start": -20, "rate": 45}}]}
```

Plan event:

```json
{"type": "asset3d", "at": 260, "until": 340, "seq": {"dir": "logo1", "f0": 240, "f1": 352},
 "x": 1500, "y": 380, "size": 420, "reason": "first mention of the product, beside the face"}
```

`Asset3D` fades and rises in over 14 frames ending on `at` and leaves from `until`. Place it in empty
space beside the face (the face box from track.json, with margin for movement), or roto it behind.
Use real logos only with the right to use them; for your own marks, export a clean single-colour SVG.

## Object fields

| Field | Default | Meaning |
|---|---|---|
| `text` / `image` | | a key in paths.json, or an SVG/PNG path relative to the shot file |
| `x`, `y` | 0 | centre on the focal plane, px from the frame centre (y up) |
| `width` / `height` | | target size in px (text: width of the word or `height` = cap height) |
| `depth` | 44 | extrusion thickness, px |
| `bevel` | 4.5 | rounded edge radius, px |
| `body` | `dark-metal` | `dark-metal`, `steel`, `gold`, `chrome`, `copper`, or a hex metal colour (+ `bodyRough`) |
| `face`, `faceDim` | `#f2f4f5` | face colour; `faceDim` is the colour before `lit` |
| `faceMetal`, `faceRough` | false, 0.26 | metallic face (logos) or painted face (type) |
| `medallion` {radius}, `relief` | | put the silhouette on a disc, raised by `relief` px |
| `in` | required unless `enter: "none"` | frame the object has fully ARRIVED (it swings in over `enterFrames`, 13, before it) |
| `out` | | frame it starts leaving (over `exitFrames`, 11) |
| `lit` | | frame the face brightens from `faceDim` to `face`, with a small nod |
| `side` | by x | swing direction (1 from the left, -1 from the right) |
| `spin` {start, rate} | | degrees, degrees per second, about the vertical axis |
| `tilt` [x, y] | | resting tilt in degrees |
| `idle` | 1 | amount of slow yaw/pitch wobble (0 = locked) |

Shot fields: `width`, `height`, `fps`, `spp` (samples per pixel; 48 for looks, 128-256 final),
`f0`/`f1`, `camera.distance` (px; perspective strength), `camera.aperture` (px; depth of field),
`light.rimA` / `light.rimB` / `light.bounce` (hex), `light.key`, `light.rim` (multipliers),
`exposure`.

## Speed and platforms

- Apple Silicon (Metal): a 1080x420 two-word frame at 128 spp renders in well under a second.
- Linux with a GPU: `RENDER3D_GL_ARGS="--use-angle=vulkan"` (or `--use-gl=egl`). Without a GPU it
  falls back to SwiftShader (CPU): correct, many times slower; drop `spp` and render overnight.
- `CHROME_PATH` to use an installed Chrome/Chromium.

## Craft rules for 3D

- Big, in the space BESIDE the head (or across the chest), never on the face. Equal padding from
  every frame edge (at least ~90 px at 1080 wide).
- It arrives on its word and leaves on its exit word, like every other effect.
- One hero moment per passage. A 3D word on every sentence is a slideshow.
- Pick the font for the series and keep it. Heavy geometric sans (ExtraBold/Black) reads best
  extruded; thin weights vanish into their own bevels.
- Light it from the set: match `rimA`/`rimB` to the practical lights in the room so it sits in the
  same space as the speaker.
- Check stills at the arrival, the hold and the exit, over the actual frame (composite them), before
  rendering the clip.
